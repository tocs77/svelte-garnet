## Overview

<code>Alarm</code> renders <code>.garnet-alarm</code> with an <code>&lt;h3&gt;</code> for <code>label</code>{' '}
and a <code>.notifications</code> region. The badge (`.count`) displays <code>notifications</code> and
uses CSS variables <code>--countColor</code> and <code>--countBackgroundColor</code> from props. A{' '}
<code>#key</code> block re-runs the <code>scale</code> transition whenever the count changes.

The bell SVG toggles <code>filled</code> vs <code>outline</code> via the <code>filled</code> prop. Class{' '}
<code>ring</code> is applied when <code>notifications &gt; 0</code>, enabling the <code>ring</code> keyframe
animation. <code>small</code> shrinks the bell and repositions the badge for a compact layout.

Styles live in the component <code>&lt;style&gt;</code> block next to <code>Alarn.svelte</code>.

## Usage in Svelte

```svelte
<script lang="ts">
  import Alarm from '$lib/components/Alarm/Alarn.svelte';

  let notifications = $state(3);
</script>

<Alarm {notifications} label="Messages" />

<Alarm
  notifications={0}
  label="Quiet mode"
  filled
  small
  countColor="#ffffff"
  countBackgroundColor="#265573"
/>
```

## Usage as a custom element

<code>garnet-alarm</code> comes from <code>customElement="garnet-alarm"</code>. Set <code>notifications</code>,{' '}
<code>label</code>, colors, <code>filled</code>, and <code>small</code> as properties on the element. Prefer
numeric <code>notifications</code> from JavaScript rather than string attributes when possible.

## Accessibility

- The bell is decorative SVG without an accessible name; provide context with <code>label</code> or an{' '}
  <code>aria-label</code> on a wrapping control if this becomes a button.
- Consider <code>aria-live="polite"</code> on the count region when <code>notifications</code> changes so
  screen-reader users hear updates.
- Continuous <code>ring</code> animation may distract some users; respect{' '}
  <code>prefers-reduced-motion</code> by disabling the animation in a future revision if you use this in
  production.
