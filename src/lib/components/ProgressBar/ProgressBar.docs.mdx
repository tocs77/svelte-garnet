## Overview

<code>ProgressBar</code> wraps a <code>.garnet-progressbar</code> container with two layout modes. When
<code>labelInside</code> is <code>true</code>, the percent text sits inside a pill-shaped fill whose
width tracks <code>progress.current</code>. When <code>false</code>, a row above the track shows
<code>labelTextOutside</code> and the percent; the bar is a fixed-height strip below.

Motion is driven by <code>Tween</code> from <code>svelte/motion</code>. An <code>$effect</code> calls
<code>progress.set(Number(progressAmt), …)</code> whenever props change. With <code>animate</code>{' '}
<code>true</code>, <code>tweenDuration</code> and <code>easing</code> control the transition; with{' '}
<code>animate</code> <code>false</code>, <code>duration</code> is <code>0</code> so the bar jumps
immediately. The bar color comes from the <code>color</code> prop on the fill element.

Styles live in the component <code>&lt;style&gt;</code> block next to <code>ProgressBar.svelte</code>.

## Usage in Svelte

```svelte
<script lang="ts">
  import ProgressBar from '$lib/components/ProgressBar/ProgressBar.svelte';

  let progressAmt = $state(0);

  function tick() {
    progressAmt = Math.min(100, progressAmt + 10);
  }
</script>

<button type="button" onclick={tick}>Advance</button>

<ProgressBar {progressAmt} labelInside={false} labelTextOutside="Uploading files…" />

<ProgressBar progressAmt={100} color="#265573" tweenDuration={800} />
```

## Usage as a custom element

<code>garnet-progressbar</code> comes from <code>customElement="garnet-progressbar"</code>. Set numeric
and boolean props as element properties from JavaScript or Svelte. Values such as <code>progressAmt</code>{' '}
and <code>tweenDuration</code> should be numbers, not strings, for predictable tweening. The{' '}
<code>easing</code> function is easiest to supply from Svelte rather than from static HTML.

## Accessibility

- Expose progress with a native <code>&lt;progress&gt;</code> or <code>role="progressbar"</code> with{' '}
  <code>aria-valuenow</code>, <code>aria-valuemin</code>, and <code>aria-valuemax</code> if you rely on
  this component for load status; the current markup is visual only.
- Percent text updates as the tween runs; pair it with a live region if screen-reader users need
  frequent announcements without overwhelming chatter.
- Prefer sufficient contrast between <code>color</code> and the track background for the outside-label
  layout where the fill is only 10px tall.
