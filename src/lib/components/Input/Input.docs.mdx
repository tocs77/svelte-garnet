## Overview

`Input` is a thin wrapper around a native `<input type="text">` that renders an
optional `<label>` and exposes its value through Svelte's `bind:value`. It is
compiled as a custom element (`<garnet-input>`) via
`<svelte:options customElement="garnet-input" />`, so it can be used both inside
Svelte components and as a plain HTML tag.

## Props

<Controls of={InputStories.Default} />

| Prop          | Type                  | Default                 | Description                                                    |
| ------------- | --------------------- | ----------------------- | -------------------------------------------------------------- |
| `label`       | `string`              | `'Label'`               | Text rendered inside the `<label>` element. Hidden when empty. |
| `placeholder` | `string`              | `'default placeholder'` | Native `placeholder` attribute on the input.                   |
| `inputName`   | `string`              | `''`                    | Native `name` attribute. Used when submitting via a form.      |
| `fieldID`     | `string`              | `''`                    | `id` of the input. The label's `for` points at this value.     |
| `disabled`    | `boolean`             | `false`                 | When `true`, disables interaction and applies a not-allowed cursor. |
| `value`       | `string \| undefined` | `undefined`             | The current input value. Supports `bind:value`.                |

### Prefilled value

Pass a `value` to render the input with an initial string. In Svelte you can
two-way bind to it:

```svelte
<script lang="ts">
  import Input from '$lib/components/Input/Input.svelte';

  let email = 'hello@garnetui.dev';
</script>

<Input label="Email" fieldID="email-field" bind:value={email} />
```

## Usage as a custom element

Because `Input.svelte` declares `customElement="garnet-input"`, it can be used
in any HTML context after the bundle is loaded:

```html
<garnet-input
  label="Username"
  placeholder="Enter your username"
  inputname="username"
  fieldid="username-field"
></garnet-input>
```

> Custom element attributes are lowercase, so `inputName` becomes `inputname`
> and `fieldID` becomes `fieldid` when used from HTML.

## Accessibility

- Always provide a non-empty `label` together with a unique `fieldID` so screen
  readers can associate the label with the input.
- When the input is `disabled`, the underlying `<input>` receives the native
  `disabled` attribute, which removes it from the tab order automatically.
