## Overview

`Tooltip` renders inside `.garnet-tooltip`. The trigger is a `<button type="button">` with class
`trigger`. Hovering enters a delayed show (`timeout`); leaving starts a delayed hide unless the pointer
moves into the tooltip panel, which cancels the hide timer. Click sets the tooltip open immediately.
When `active` is `true`, a `div` with `role="tooltip"` appears below the trigger (`transition:fade`).
Content is plain text unless `showHtml` is `true`, in which case `tip` is rendered with `{@html}`.

Styles live in the component `<style>` block next to `Tooltip.svelte`.

## Usage in Svelte

```svelte
<script lang="ts">
  import Tooltip from '$lib/components/Tooltip/Tooltip.svelte';
</script>

<Tooltip
  id="password-help"
  label="Password requirements"
  tip="Use at least 12 characters with letters, numbers, and symbols."
/>

<Tooltip
  label="Formatted help"
  tip="<strong>Note:</strong> Billing runs at month end."
  showHtml
  timeout={0}
/>
```

## Usage as a custom element

`<garnet-tooltip>` comes from `customElement="garnet-tooltip"`. Set `id`, `label`, `tip`, `timeout`, and
`showHtml` as properties on the element. Visibility is managed internally; the trigger and tooltip panel
are part of the component markup.

## Accessibility

- The trigger uses `aria-describedby` pointing at the tooltip `id` only while the tip is visible.
- The tooltip region uses `role="tooltip"` and `aria-label={label}`.
- Escape closes the tooltip and moves focus off the trigger via `blur()`.
- Pointer handlers live on the same element as `role="tooltip"`, satisfying Svelte’s static-element
  interaction rules.
- When using `showHtml`, only pass trusted markup; `{@html}` does not sanitize content.
