## Overview

`Spinner` switches on `variant`:

- **`circle`** — a `.circle` element with a partial border and the
  `rotate-circle` keyframes.
- **`jumper`** — three `.jumper` elements inside a `.jumper-wrap` container
  (positioned box), each using the `bounce` keyframe animation with a staggered
  delay.

Both branches set inline `--size`, `--color`, and `--duration` for `Spinner.css`.

`size` is a **string** (default `'60'`) and is suffixed with `px` in the markup.

`variant` is an `export let` with type <code>'circle' | 'jumper'</code> (default
<code>'circle'</code>). <code>unit</code> and <code>pause</code> are
<code>export const</code> placeholders for future use.

## Usage in Svelte

```svelte
<script lang="ts">
  import Spinner from '$lib/components/Spinner/Spinner.svelte';
</script>

<Spinner size="48" color="#0f766e" duration="0.9s" variant="circle" />

<Spinner size="40" color="#7c3aed" duration="1s" variant="jumper" />
```

## Usage as a custom element

`<garnet-spinner>` comes from `customElement="garnet-spinner"`. Pass
`variant="jumper"` or `variant="circle"` from HTML or set the property in
JavaScript after upgrade, along with `size`, `color`, and `duration`.

## Accessibility

- The spinner is purely decorative unless you add copy or ARIA around it.
- Continuous motion can be distracting; consider `prefers-reduced-motion` in
  CSS or a paused state when you wire up `pause`.
