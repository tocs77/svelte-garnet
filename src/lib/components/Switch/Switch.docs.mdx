## Overview

<code>Switch</code> wraps a native <code>&lt;input type="checkbox"&gt;</code> inside a
<code>&lt;label&gt;</code>. The checkbox is visually hidden but still drives state via
<code>bind:checked=&#123;isChecked&#125;</code>. The visual track/thumb is a sibling <code>&lt;span&gt;</code> that
uses <code>::before</code> and <code>::after</code> pseudo-elements; checked state moves the thumb and
changes track color.

Container classes are composed from <code>switch-container</code>, optional custom <code>css</code>, and
<code>disabled</code>. The visual span classes are composed from <code>switch</code> and optional
<code>switch-&#123;size&#125;</code>. Disabled mode dims the control and changes cursor behavior.

Styles live in the component <code>&lt;style&gt;</code> block next to <code>Switch.svelte</code>.

## Usage in Svelte

```svelte
<script lang="ts">
  import Switch from '$lib/components/Switch/Switch.svelte';

  let isChecked = false;
</script>

<Switch
  id="email-updates"
  label="Email updates"
  bind:isChecked
/>

<Switch
  id="readonly-toggle"
  label="Locked setting"
  isChecked={true}
  disabled
/>
```

## Usage as a custom element

<code>garnet-switch</code> comes from <code>customElement="garnet-switch"</code>. Set
<code>id</code>, <code>label</code>, <code>css</code>, <code>size</code>, <code>isChecked</code>, and
<code>disabled</code> as element properties from JavaScript or Svelte.

## Accessibility

- The control uses a native checkbox with <code>role="switch"</code>, so it supports keyboard interaction.
- Keep <code>label</code> meaningful (or provide external labeling) so screen readers announce purpose.
- Ensure unique <code>id</code> values when rendering multiple switches in one view.
