<Title>Breadcrumbs</Title>

<Subtitle>
  Inline navigation trail, registered as the <code>garnet-breadcrumbs</code> custom element. In
  Storybook it appears under <strong>Action Components → Breadcrumbs</strong>. Items come from the{' '}
  <code>breadcrumbItems</code> array: every segment except the last is rendered as a link; the final
  segment is plain text for the current page. Between segments you can show a text <code>divider</code>{' '}
  or an Iconify icon when <code>iconFamily</code> and <code>iconName</code> are both set.
</Subtitle>

## Overview

The component maps <code>breadcrumbItems</code> to a single horizontal <code>&lt;ul&gt;</code>. For each
item after the first, it inserts either a <code>&lt;span&gt;</code> with <code>divider</code> (default{' '}
<code>/</code>) or an <code>&lt;Icon&gt;</code> from <code>@iconify/svelte</code> using the{' '}
<code>{'{iconFamily}:{iconName}'}</code> pattern (see [Iconify icon sets](https://icon-sets.iconify.design/)).
If either <code>iconFamily</code> or <code>iconName</code> is empty, the text divider path is used; for a
reliable icon divider, set both props.

Intermediate items use <code>&lt;a href&gt;</code> with <code>data-testid="breadcrumbLink"</code> on each
link. Styles (colors, list layout) live in the component <code>&lt;style&gt;</code> block.

## Usage in Svelte

```svelte
<script lang="ts">
  import Breadcrumbs from '$lib/components/Breadcrumbs/Breadcrumbs.svelte';

  const breadcrumbItems = [
    { text: 'Home', href: '/' },
    { text: 'Settings', href: '/settings' },
    { text: 'Profile', href: '' },
  ];
</script>

<Breadcrumbs {breadcrumbItems} />

<Breadcrumbs {breadcrumbItems} divider="›" />

<Breadcrumbs {breadcrumbItems} iconFamily="mdi" iconName="chevron-right" />
```

## Usage as a custom element

<code>garnet-breadcrumbs</code> comes from <code>customElement="garnet-breadcrumbs"</code>. Arrays such as{' '}
<code>breadcrumbItems</code> are easier to set from Svelte or JavaScript (property assignment after
upgrade) than from static HTML alone.

## Accessibility

- The trail is a list (<code>&lt;ul&gt;</code> / <code>&lt;li&gt;</code>), which helps screen readers
  treat segments as a related sequence.
- Only non-final segments are links, which matches the common “current page is not a link” pattern.
- Consider wrapping the component in a <code>&lt;nav&gt;</code> (or adding <code>aria-label</code>) in
  the parent layout if this is the primary breadcrumb navigation for the page.
